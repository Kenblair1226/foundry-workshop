## Learning objectives

By the end of this workshop, participants will be able to:

1. Explain the Azure AI Foundry architecture (hubs, projects, connections, model catalog).
2. Provision Foundry resources through the portal and understand the resource hierarchy.
3. Deploy models from the catalog and invoke them with the `azure-ai-projects` and `azure-ai-inference` SDKs.
4. Apply prompt-engineering techniques and run automated evaluations.
5. Implement a Retrieval-Augmented Generation (RAG) solution using Azure AI Search.
6. Build, equip with tools, and deploy an agent with the Azure AI Foundry Agent Service.
7. Apply Responsible AI practices (content safety, evaluation, observability).
